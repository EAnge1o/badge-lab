# Achievement notes

Verified against the community-maintained achievement list on 2026-11-14.
GitHub does not publish an official, complete list, and thresholds can change.

## Currently earnable

- **Pull Shark** - merged PRs in public repositories: 2 / 16 / 128 / 1024.
- **Starstruck** - stars on a repository you own: 16 / 128 / 512 / 4096.
  Self-stars do not count.
- **Pair Extraordinaire** - co-authored commits in merged PRs: 1 / 10 / 24 / 48.
  The `Co-authored-by: Name <verified-email>` trailer must be in the commit
  message itself, after a blank line.
- **Galaxy Brain** - Q&A discussion answers marked accepted: 2 / 8 / 16 / 32.
  Only the discussion author or a maintainer can mark an answer.
- **Quickdraw** - close an issue or PR within 5 minutes of opening it.
- **YOLO** - merge a PR without a review (only do this on a repo you own).
- **Public Sponsor** - sponsor someone publicly via GitHub Sponsors.
- **Finishing Touch** - merged PRs that improve GitHub's own UI.

## Not obtainable any more

- Heart On Your Sleeve and Open Sourcerer were briefly enabled by a backend
  error in 2026 and switched off again.
- Arctic Code Vault Contributor and Mars 2020 Contributor are retired.

## Practical gotchas

1. Private-repo PRs do not count for Pull Shark.
2. A squash merge can drop a `Co-authored-by` trailer, so a plain merge
   commit is safer when you care about attribution.
3. Achievement processing is asynchronous; allow up to 48 hours.
4. Deleting the source repository or making it private can remove the badge.
5. Achievements can be hidden individually in profile settings - check
   Settings > Public profile > Achievements if nothing shows up.
