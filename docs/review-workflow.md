# Review workflow note

A short record of how this repository handles review:

1. Open a branch, make one reviewable change, and open a pull request.
2. Request a review from a collaborator with push access.
3. Merge only after the review, unless the change is a trivial docs fix on a
   repository you own and the review has not started yet.

This file was added to exercise the "review requested, merged before review"
path in a repository with two distinct accounts.
